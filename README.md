# Heart Disease Risk Analysis Prediction using Machine Learning

Overview:
This project explores a heart disease dataset (heart.csv) to understand which patient features are linked to heart disease, and prepares the data for machine learning.

What's Inside
Exploratory Data Analysis: shape, data types, summary statistics, duplicates, and missing values
Data Cleaning: invalid zero values in Cholesterol and RestingBP replaced with the mean of valid values
Visualization: histograms, count plots, box plot, violin plot, and a correlation heatmap
Preprocessing: one-hot encoding of categorical features and standard scaling of Age, RestingBP, Cholesterol, and MaxHR
Tech Stack

Python, NumPy, pandas, Matplotlib, Seaborn, scikit-learn
